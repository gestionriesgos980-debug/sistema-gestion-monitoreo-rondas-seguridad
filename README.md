# CAM-RONDAS LAB-04 — TECCHNEX

Versión de laboratorio para pruebas controladas. No es una versión de producción.

## Publicación
- Archivo de entrada para GitHub Pages: `index.html`.
- Archivo de referencia con nombre de laboratorio: `CAM-RONDAS-LAB-04.html`.
- Para activar GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Alcance comprobable en este laboratorio
- Registra rondas, puntos de control y novedades localmente en el navegador.
- Rechaza repetir un punto dentro de la misma ronda.
- Aplica un intervalo mínimo de 3 minutos entre marcaciones válidas.
- La captura GPS requiere permiso del dispositivo y contexto seguro HTTPS; comprobar en el teléfono.
- No incluye autenticación real de servidor, integración real de QR/NFC ni sincronización remota multiusuario.

## Precaución
Usar únicamente datos ficticios durante la demostración. Conservar la ZIP original como respaldo. No reemplaza ni modifica productos estables de TECCHNEX.
